0. Grundprinzip

Der Editor läuft vollständig im Browser. Deine PNG-Dateien werden lokal geladen und lokal im Canvas verarbeitet. Der Editor erstellt daraus Frames, Animationen und Exportdaten für dein Canvas-/BudStorm-Game.

Empfohlener Workflow: PNG laden → Transparenz bereinigen → Frames erzeugen/croppen → Animation bauen → Pivot/Boxes setzen → Exportieren.

1. PNG laden

  1. Klicke oben im Editor auf PNG laden.
  2. Wähle dein Sprite-Sheet im PNG-Format aus.
  3. Prüfe links im Bereich Sheet, ob Bildname und Bildgröße korrekt angezeigt werden.
  4. Die Asset-ID wird automatisch aus dem Dateinamen erzeugt. Passe sie bei Bedarf an, bevor du exportierst.
Wichtig: Für saubere Runtime-Assets immer PNG verwenden. JPG hat keine echte Transparenz und erzeugt Kompressionsartefakte.

2. Farbtransparenz auswählen

  1. Im Bereich Transparenz / Hintergrund kannst du die Transparenzfarbe manuell über das Farbfeld wählen.
  2. Alternativ klickst du auf Farbe picken.
  3. Klicke danach im Sheet-Canvas exakt auf die Hintergrundfarbe, die transparent werden soll.
  4. Der gewählte Farbwert erscheint im Farbfeld und im Statusbericht.

Toleranz

Die Toleranz steuert, wie stark ähnliche Farben mitentfernt werden. Kleine Werte entfernen nur exakt gleiche Farben. Große Werte entfernen auch Farbsäume und Antialiasing-Ränder.

  • 0–10: nur sehr exakte Farben
  • 20–45: typische Pixelart-Hintergründe
  • 50–100: stärkere Farbsäume oder komprimierte Vorlagen

Soft Edge

Soft Edge erzeugt weicher auslaufende Alpha-Kanten. Für harte Pixelart meistens 0 lassen. Für weich gezeichnete Sprites kann 4–16 sinnvoll sein.

3. Automatische Hintergrundentfernung

  1. Klicke auf Auto-Hintergrund.
  2. Der Editor liest die vier Eckpixel des Bildes.
  3. Aus diesen Ecken wird eine Hintergrundfarbe berechnet.
  4. Alle Pixel innerhalb der eingestellten Toleranz werden transparent gesetzt.
Auto-Hintergrund funktioniert am besten, wenn die vier Ecken tatsächlich Hintergrund enthalten. Wenn dort Sprite-Teile liegen, nutze besser Farbe picken.

Original wiederherstellen

Mit Original kannst du jederzeit zum geladenen Originalbild zurückkehren. Danach kannst du andere Toleranzen testen.

PNG exportieren

Mit PNG exportieren speicherst du das aktuell bereinigte PNG inklusive Alpha-Transparenz.

4. Frames erzeugen

Raster-Methode

  1. Setze Frame W und Frame H.
  2. Setze optional Offset X/Y, wenn das Sheet Randabstand hat.
  3. Setze optional Gap X/Y, wenn zwischen Frames Abstand liegt.
  4. Klicke auf Frames aus Raster erzeugen.

Drag-Crop-Methode

  1. Wähle das Tool Drag-Crop.
  2. Ziehe im Sheet-Canvas einen Rahmen um den gewünschten Frame.
  3. Beim Loslassen wird ein neuer Frame erzeugt.
  4. Mit Select/Move kannst du Frames danach verschieben und an den Ecken skalieren.

5. Animation bauen

  1. Lege rechts im Bereich Animationen eine Animation an oder nutze idle.
  2. Wähle Anim-Paint im Sheet-Werkzeug.
  3. Klicke Frames im Sheet an, um sie zur aktiven Animation hinzuzufügen oder zu entfernen.
  4. Sortiere Frames in der Sequenz mit ↑ und ↓.
  5. Stelle FPS und Loop ein.

6. Preview, reine Animation und Overlays

In der Preview kannst du Animation, Pivot und Collision-Boxes kontrollieren. Die Hitbox/Hurtbox/Attackbox sind standardmäßig 80% transparent, damit der Sprite sichtbar bleibt.

Reine Animation anzeigen

  1. Boxes ausschalten.
  2. Pivot ausschalten.
  3. Onion ausschalten.
  4. Mit Play die reine Animation prüfen.

Onion-Skin

Onion-Skin zeigt vorherige und nächste Frames halbtransparent an. Das hilft beim Timing, ist aber für die finale Animationskontrolle abschaltbar.

7. Pivot und Hit/Hurt/Attack-Boxes

Pivot setzen

  1. Wähle das Preview-Tool Pivot.
  2. Klicke oder ziehe im Preview-Canvas auf den gewünschten Ursprungspunkt.
  3. Der Pivot wird frame-lokal in Pixeln gespeichert.

Boxes zeichnen und verschieben

  1. Wähle links den Box-Typ: hit, hurt oder attack.
  2. Wähle rechts Box Draw, um eine Box neu zu ziehen.
  3. Wähle Box Move, um die aktive Box zu verschieben.
  4. Ziehe an den Eckpunkten, um die Box zu skalieren.

8. Export

  • Projekt JSON: vollständiges editierbares Projekt für spätere Nachbearbeitung.
  • BudStorm JSON: Runtime-Atlas mit Frames, Pivot, Boxes und Animationen.
  • BudStorm JS: eigenständige JS-Datei, die sich unter window.BudStormSpriteAtlases[assetId] registriert.
  • PNG: aktuell bereinigtes Sprite-Sheet mit Transparenz.
  • Animation Strip PNG: horizontales Strip-PNG der aktiven Animation.
